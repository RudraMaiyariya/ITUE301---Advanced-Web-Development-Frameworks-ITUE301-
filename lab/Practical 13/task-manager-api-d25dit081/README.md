# Practical 13: AI API Integration into a Web Application

This project securely integrates an external Artificial Intelligence service (Google Gemini / OpenAI API) into the full-stack Task Management application with server-side key security, graceful degradation, per-user rate limiting, and responsible AI disclaimers.

---

## 🚀 Key Features

- **Secure Backend AI Gateway (`POST /api/ai/generate-description`)**:
  - The AI API key is strictly maintained and consumed on the Node/Express backend (`.env`). It is **never** exposed to the frontend or browser network requests.
- **Context-Aware Task Generation**:
  - Automatically drafts a structured 2-sentence description, suggests task priority (`low`, `medium`, `high`), and proposes deadlines based on the task title.
- **Graceful Degradation Architecture**:
  - If the external AI service times out, experiences rate limits, or is unreachable, an intelligent fallback assistant generates contextual descriptions locally. The application never crashes or halts user task creation.
- **Frontend Loading State (Supplementary Q1)**:
  - Disables the button and renders an interactive loader (`⏳ Analyzing task title and generating structured description...`) while awaiting the AI model response.
- **Per-User Rate Limiting (Supplementary Q2)**:
  - Enforces a strict cooldown of maximum 1 AI generation request per user per minute (returns `429 Too Many Requests` with remaining seconds) to prevent API quota exhaustion and abuse.
- **Responsible AI Disclaimer (Supplementary Q3)**:
  - Renders a prominent warning banner:
    `⚠️ AI Disclaimer: This content is generated by AI. Please review and verify accuracy before submitting.`
  - Content remains fully editable in the textarea, ensuring human-in-the-loop oversight.

## 🔄 Architectural Workflow

```text
React Frontend (User types title: "Fix authentication login error")
      │
      ▼ Clicks "✨ Auto-Generate with AI" (Enters Loading State)
Express Backend: POST /api/ai/generate-description
      │
      ├── [Step 1] Rate Limit Check: Under 1 req/min? ──► If NO: Return 429
      │
      ├── [Step 2] Read GEMINI_API_KEY from .env (Server-side ONLY)
      │
      ▼ [Step 3] Call External AI Model (Google Gemini 1.5 Flash)
      │
 ┌────┴─────────────────────────────┐
 │                                  │
 ▼ Success                          ▼ Failure / Timeout / Offline
Parse JSON response                Activate Graceful Degradation Engine
 │                                  │
 └────────────────┬─────────────────┘
                  │
                  ▼
Attach Responsible AI Disclaimer & Send Response
                  │
                  ▼
React Frontend renders editable text & disclaimer in UI
```

## ⚙️ How to Run Locally

### 1. Configure Environment (Optional)
In `.env`:
```env
GEMINI_API_KEY=your_gemini_api_key_here
PORT=5000
```
*(If no API key is set, the built-in Graceful Degradation assistant automatically generates context-aware suggestions without failing!)*

### 2. Start Backend Server
```bash
node server.js
```

### 3. Start Frontend Client
```bash
npm run dev
```
Navigate to `http://localhost:5173/tasks`, type a title (e.g., `Deploy Docker container to production`), and click **✨ Auto-Generate with AI**!
